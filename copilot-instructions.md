---
description: "Automatically wrap comments to improve readability and maintain consistent formatting."
---

When writing or editing code comments, automatically wrap them to fit within 80 characters per line. Break long comments at natural word boundaries and maintain proper indentation for multi-line comments.

---
description: "Do not use semicolons at the end of statements in JavaScript or TypeScript files."
applyTo: **/*.js, **/*.ts
---
In JavaScript and TypeScript files, avoid using semicolons at the end of statements. Rely on automatic semicolon insertion (ASI) to handle statement termination. This promotes cleaner and more concise code style.
